Atue como um Desenvolvedor Full-Stack Sênior (React Native e Node.js). Sua missão é desenvolver e refatorar uma aplicação de Gestão Financeira com base em um template inicial, implementando novas funcionalidades no Frontend e construindo um Backend robusto com banco de dados.

Você deve gerar o código necessário passo a passo, garantindo que a integração entre Frontend e Backend funcione perfeitamente. Siga rigorosamente os requisitos abaixo.

### 🎯 1. REQUISITOS DO BACKEND (Node.js + Banco de Dados)
O backend deve deixar de usar dados em memória e passar a persistir as informações em um banco de dados. 
- Crie a modelagem do banco de dados para `Categorias` e `Transações`.
- A API deve possuir validação de dados utilizando Zod.
- Crie as seguintes rotas e garanta que elas atendam aos contratos de teste abaixo:

**Contratos da API (Endpoints):**
1. Health-check: `GET /` -> Retorno esperado: `{ "ok": true, "name": "gestao-financeira-api" }`
2. Listar categorias: `GET /categories` -> Deve retornar as categorias (incluindo as 5 fixas do seed).
3. Criar categoria: `POST /categories` -> Body: `{ "name", "displayName", "icon", "background", "isIncome" }`. Retorno: `201 Created` com o objeto e ID.
4. Atualizar categoria: `PUT /categories/:id` -> Body para atualização parcial (ex: `{ "displayName": "..." }`).
5. Excluir categoria: `DELETE /categories/:id` -> Retorno: `204 No Content`. Regra de negócio: Se tentar excluir uma categoria padrão (ex: 'income'), retornar `400` com erro "Categorias padrão não podem ser excluídas".
6. Criar transação: `POST /transactions` -> Body: `{ "description", "value", "date", "categoryId" }`. Retorno: `201 Created` com a categoria aninhada. O Zod deve barrar dados inválidos (ex: description vazia) retornando `400` com "error": "Dados inválidos" e os detalhes.
7. Listar transações: `GET /transactions` -> Deve retornar a lista de transações com as categorias expandidas/aninhadas.
8. Excluir transação: `DELETE /transactions/:id` -> Retorno: `204 No Content`.

*Nota:* O backend deve estar preparado para rodar em `http://localhost:3000`.

### 📱 2. REQUISITOS DO FRONTEND (React Native)
Implemente as seguintes melhorias no template do aplicativo:
- **Autenticação:** Crie uma tela de Login com validação de acesso.
- **Boas-vindas:** Exiba uma mensagem de boas-vindas com o nome do usuário autenticado na tela principal.
- **Filtros:** Adicione um filtro de "Mês/Ano" nas telas de Lista de Transações e na tela de Resumo.
- **Visualização de Dados:** Implemente gráficos (ex: gráfico de pizza) na aba de resumo para visualizar as despesas/receitas por categoria.
- **Gestão de Transações:** Permita a edição e exclusão de transações acionadas por um "toque longo" (long press) que abre um Modal de opções.
- **Gestão de Categorias:** Adapte o frontend para consumir e criar novas categorias customizadas direto do banco de dados (além das 5 fixas).
- **Integração:** Crie um Client HTTP (ex: Axios ou Fetch) para consumir os endpoints criados no Backend.
